# Algorithms Library

A collection of algorithms implemented and visualized by me in Python using Pygame.

The repository is mainly a learning project where I implement algorithms from scratch, experiment with different approaches and create visualizations to better understand how they work.

## Algorithms

### 01 — A*
A pathfinding algorithm that searches for the shortest route between two points while using a heuristic to guide the search toward the destination.

### 02 — Dijkstra's Algorithm
A shortest-path algorithm that explores a weighted graph without using a heuristic, allowing shortest paths from one starting point to multiple destinations to be found.

### 03 — Bidirectional Search
A pathfinding approach that searches simultaneously from the starting point and the destination, reducing the explored area until both searches meet.

### 04 — Minimum Spanning Tree
An algorithm that connects all vertices of a weighted graph while minimizing the total cost of the selected edges.

### 05 — Force-Directed Graph Layout
A graph-layout optimizer based on several simulated forces, including edge-length correction, node repulsion, edge-crossing reduction and node-edge repulsion, used to produce more readable graph visualizations.
